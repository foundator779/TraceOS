# Four-minute submission demo

Use a real human voice. Keep the product workflow on screen except for the final Google Cloud proof shots.

| Time | Screen and narration target |
|---|---|
| 0:00–0:25 | Open on the synthetic sign-in alert. Click **Run evidence replay**. State the problem: investigations fail when autonomous agents cannot prove where a conclusion came from. |
| 0:25–0:55 | Show the fleet and incoming image/audit evidence. Explain that each identity has separate tools and evidence scopes. |
| 0:55–1:30 | Open **Replay**. Select the image, visual observation, hypothesis, and finding. State that Gemini extracts visible facts but cannot write findings. |
| 1:30–1:55 | Show the reporting identity’s raw-evidence deny and approved verified-findings recovery. Do not call a local fallback managed. |
| 1:55–2:20 | Select the stopped unsupported claim. Show Fleet Integrity rejecting `EVID-019` and the bounded replay using `EVID-003`. |
| 2:20–2:45 | Trigger the seven-day resume. Show generation two restoring the same case memory and resolving the open question. |
| 2:45–3:10 | Open **Report**, then **Training**. Show Gemma `SUPPORTED`, Veo and Lyria `READY`, the `$0.442` ledger, hashes, and the `NOT EVIDENCE` wall. |
| 3:10–3:35 | Play a few seconds of the reconstruction and audio. Explain that generated media is useful training output but has no path back into a finding. |
| 3:35–3:58 | Show Agent Runtime, Cloud Run revision, authenticated Pub/Sub worker, private training bucket, and the three model invocation IDs. End on the operational outcome. |

Do not show credentials, private evidence, hidden reasoning, or a service that has not been successfully verified.
