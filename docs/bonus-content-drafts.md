## Article outline

**Title:** Why autonomous forensic agents need an evidence replay, not another chat window

1. The operational problem: fast conclusions without provenance increase review time.
2. The TraceOS boundary: workers observe, hypotheses remain unverified, and a separate verifier promotes findings.
3. Multimodal evidence: Gemini extracts observable facts from an image without inheriting instructions from it.
4. Security and recovery: fail-closed evidence inspection, scoped identities, denied raw access, and bounded replay.
5. Production lesson: a simple visual proof path is easier to audit than hidden agent reasoning.

## Social post draft

TraceOS turns an autonomous forensic investigation into an evidence replay. An examiner can follow a screenshot and cloud event through scoped agent observations, a rejected unsupported claim, independent verification, and the final report—without exposing hidden reasoning or blurring synthetic and live sources.
